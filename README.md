# Hassan Al-Nahari — AIE100 Portfolio (Red / Black / Cream)

A responsive, static, five-page portfolio website with no external dependencies. This redesign uses **exactly these named brand colors:** `#D80A10`, `#8B100F`, `#280000`, `#030201`, `#FCF3F2` (plus opacity-based variants).

## Open the site
Extract the ZIP, then double-click `index.html`.

## What to edit
- `index.html` — homepage introduction, summary and featured projects
- `about.html` — background and career interests
- `portfolio.html` — four projects, each expandable; buttons filter laboratory vs. campus activities
- `reflections.html` — journal reflections
- `contact.html` — email and telephone
- `assets/site.css` — color tokens, layout, typography and motion
- `assets/site.js` — mobile menu, project filters, copy buttons, progress indicator and light animations

Change the values in `:root` of `assets/site.css` for any brand adjustment. No fonts, images, API keys, forms or tracking scripts are required.

## GitHub Pages
1. Create a public repository in GitHub or open the repository hosting your current portfolio.
2. Upload the **five HTML files and entire `assets` folder** to the repository root (do not upload the ZIP as-is).
3. If this updates an existing repo, replace the matching HTML and assets files, then commit.
4. Under **Settings → Pages**, choose **Deploy from a branch**, branch `main`, and folder `/(root)`.
5. Wait for deployment; your URL can stay the same.

## Accessibility and editing
- The site uses semantic HTML, high contrast text, visible keyboard focus, native details/summary, and reduced-motion support.
- On mobile, use the Menu control. On the Portfolio page, use the category tabs to filter.
- The Contact page displays a public email and telephone; remove the phone number if you prefer not to publish it.
- Project results are academic group laboratory values, not commercial AI projects. The campus familiarization work was individual coursework.

## Design reference
Color palette is user-supplied. The Figma site URL could not be fully inspected in this environment, so this is an original design that follows the palette rather than a pixel-for-pixel copy of the Figma layout.
